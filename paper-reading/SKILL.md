# 论文分阶段阅读

帮助用户从整体认识逐步深入至方法机制、技术重建与证据理解。**四阶段是理解深度递进，不是四遍重复的论文总结。** 采用自然、清晰、教学式的中文，不强制审稿、批判、提出创新点或套用固定长模板。

## 1. 根据请求确定阶段

| 用户意图 | 动作 |
| --- | --- |
| 快速阅读、简要了解、主要观点、核心结论 | 只执行**阶段一**，完成即停止 |
| 精读、深入阅读、带我读论文 | 默认从**阶段一**开始，完成后等待用户确认进入第二阶段 |
| 继续、下一阶段 | 对同一论文推进**一个**阶段；若在第四阶段则不再推进 |
| 进入第 N 阶段、讲核心方法、数学推导、实验结果 | 直接执行指定阶段或根据语义选择对应阶段 |
| 没看懂 X、为什么 Y、这里怎么推导 | 回答具体疑问，**不擅自改变当前阶段** |

四个阶段：

1. **精要概括**：研究问题、动机、基本思路、主要发现与必要限定。
2. **核心方法理解**：为什么如此设计、核心思想、组件及输入到输出的过程。
3. **技术与数学细节**：定义、假设、推导、证明、算法或其他核心研究技术。
4. **研究结果理解**：主要结论与证据如何对应、图表/定理/实验究竟说明什么、成立范围。

**默认每轮只完成一个阶段**，不要因用户要求“精读”就在一条回答里输出全部四阶段。用户指定阶段时直接进入，只补足其不可缺少的前置概念。不因追问提前跳到后续阶段；可以在当前阶段内持续讨论。

## 2. 读取并复用论文资料

1. 确认论文标题、作者、年份、版本。优先阅读用户提供的原文；必要时查找论文正式或作者公开版本。标题存在歧义时先核实，不能凭相似题目编造内容。
2. 辨别已获得的是完整 PDF（含图表）、全文文本、部分章节还是仅摘要。资料不完整时按真实可见内容降级解释。
3. 首次建立**轻量论文索引**：章节与页码、核心公式/定理、关键图表、附录及论文类型；只需知道“到哪里找什么”，不必预先完整分析全部内容。
4. 后续阶段复用同一论文索引与此前已经解释的内容；定向读取本阶段所需章节，避免每轮重头总结，也不要仅因上下文够长就一次性依赖整篇全文。
5. 在当前对话中维护简要状态：论文身份/版本、当前阶段、已经解释的概念与数学符号、关键来源位置、用户未解决的疑问。跨会话若缺少必要上下文，应询问用户论文或进度，不要假装记得。
6. 判断论文类型（允许多类），按需阅读 [论文类型调整](references/paper-types.md)。对非数学论文，第三阶段解释研究技术和论证细节，而不强行制造公式。

## 3. 只加载当前阶段的详细指南

- **阶段一**：读取 [精要概括](references/stage-1-overview.md)。
- **阶段二**：读取 [核心方法理解](references/stage-2-method.md)。
- **阶段三**：读取 [技术与数学细节](references/stage-3-technical.md)。
- **阶段四**：读取 [研究结果理解](references/stage-4-results.md)。

所有阶段同时遵守 [原文依据与准确性](references/evidence-rules.md)。除确有必要，不加载其余阶段的细则；按需定位原文、表格和附录。

## 4. 讲解与交互规则

- **先说清用途与逻辑，再讲术语、公式或例子**。按照用户的实际知识背景调整，不重复已经懂的基础，对“没看懂”的局部深入解释。
- 用论文主线决定内容优先级。重要背景只补所需的最少部分；不逐条照搬全部公式、图表、参考文献和附录。
- 例子、低维特例、数据流或图示仅在有助理解时使用；为教学构造的例子与论文真实结果必须区分。
- 不强制每阶段同样篇幅或固定栏目。简单论文可以简短，复杂论文深入；用户说“简要”则压缩。
- 技术极复杂时，**允许阶段三在阶段内部拆成多次讲解**，逐块讨论并等待用户确认，但仍视为第三阶段。
- 不主动添加论文批判、创新建议、改进策略、复现代码。除非用户要求，或限制条件对理解结论不可或缺。
- 每轮结尾在适当情况下只提示**下一阶段**，例如“如果这部分清楚了，可以进入第三阶段的具体推导”；等待用户决定。快速阅读阶段一结束无须主动推进。

## 5. 完成门槛

- **阶段一**：能解释研究什么、为什么、怎么大致做、发现什么以及必要的结论范围。
- **阶段二**：能解释为什么采用这种设计、关键机制如何从输入走向输出。
- **阶段三**：关键定义、假设、数学/算法依赖清楚，必要时可以重建核心技术；缺少证据的推导明确标记。
- **阶段四**：主要结论能定位到直接证据，实际观察、作者解释及适用范围彼此区分。

完成当前门槛便停止，不为填充模板扩写，不自动推进下一阶段。
